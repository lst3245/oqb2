Install Markup as an app

Install once for a full-screen drawing experience. After installation you can open images faster — especially on Android.

Android (Chrome)

  1. Open this page in Chrome.
  2. Tap the browser menu (⋮) → Install app or Add to Home screen.
  3. Launch Markup from your home screen.
  4. To annotate a photo: open it in Gallery/Photos → Share → choose Markup.

iPhone / iPad (Safari)

  1. Open this page in Safari (required for install).
  2. Tap Share () → Add to Home Screen → Add.
  3. Launch Markup from your home screen.
  4. To bring in an image: use the Share shortcut (below), Import, or paste inside Markup.

iOS note: Native Share → Markup with an image only works on Android. On iOS, use Import → Paste from clipboard or the optional Share shortcut below.

Share images via Shortcut (like PairDrop)
