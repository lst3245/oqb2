Export / Import

Export and import question tags, topics/subtopics, and chapters/subchapters as CSV files. Useful for transferring data between different instances of the system.

Question Tags

Export/import the tagging data for each question (topics, subtopics, chapters, metadata). Uses nominal question IDs (e.g. MATC_DSE_2012_P2_Q1) and actual names instead of database IDs, so the file is portable across system instances.

Export

CSV columns: qid, subject, major_topic, major_subtopic, minor_topics (;-separated), subtopics (;-separated), chapter, subchapter, section, level, q_type, correct_percentage, description, answer, comment

Import

Upload a CSV in the same format. Questions are looked up by qid; topics/subtopics/chapters are matched by name. Questions or names not found in the database are skipped with warnings.

Topics & Subtopics

Export/import the topic and subtopic hierarchy for a subject. Each row is either a topic (with blank subtopic columns) or a subtopic under a topic.

Export

CSV columns: subject_id, topic_name, topic_sort_order, subtopic_name, subtopic_sort_order, subtopic_hidden

Import

Upload a CSV with the same format. Existing topics/subtopics are matched by name; new ones are created automatically. Sort order and hidden flags are updated.

Chapters & Subchapters

Export/import the chapter and subchapter hierarchy for a subject. Same structure as topics: each row is a chapter or a subchapter under a chapter.

Export

CSV columns: subject_id, chapter_name, chapter_sort_order, subchapter_name, subchapter_sort_order, subchapter_hidden

Import

Upload a CSV with the same format. Existing chapters/subchapters are matched by name; new ones are created. Sort order and hidden flags are updated.
