AI Prompts System Settings
These OpenAI-compatible endpoints power the AI Tools feature (image proofreading and Markdown generation) on the Question Management page. Local servers (Ollama, LM Studio, vLLM) and cloud providers (OpenAI, OpenRouter, Poe) all work; point base_url at the API root (e.g. https://api.openai.com/v1, https://openrouter.ai/api/v1, https://api.poe.com/v1). Use Chat Completions for most endpoints; choose Responses for Poe reasoning models. OpenRouter GPT-5.5 supports reasoning via Chat Completions. API keys are stored encrypted; leave the key blank to fall back to the LLM_API_KEY in .env. Image operations require a vision-capable model.
