These templates drive every AI feature (proofreading, Markdown generation, the dashboard Explain tutor, the figure detector, and PDF Batch Import). Each prompt supports multiple named variants: the editable built-in default plus any customs you create. The active variant is what every LLM endpoint uses by default; pin specific endpoints to a different variant with the endpoint chips under the editor. FORMAT items hold the output-format rules — they are injected into the system prompt and re-appended at the end of the user turn (some models under-weight system-role formatting rules). Changes apply immediately to the running server.
Variable syntax: {{ '{{varname}}' }} — double-braces. Single { / } are literal so JSON examples like {"status": "ok"} pass through unchanged.
